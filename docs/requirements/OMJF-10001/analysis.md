# 需求分析（Git分支选择器半弹框）

## 需求概述
> 实现一个从底部拉起的半弹框，用于展示和操作Git分支，支持三栏布局、分支切换/合并、文件diff对比等功能。

## 业务背景
- **触发条件**：点击右下角的分支按钮
- **核心场景**：用户需要快速查看分支列表、切换分支、合并分支、查看改动文件
- **预期效果**：提供流畅的分支管理体验，减少操作步骤

## 功能需求

### 1. 半弹框容器
- **位置**：从底部向上滑入，占据屏幕60-70%高度
- **动画**：流畅的滑入/滑出动画（200-300ms）
- **遮罩**：半透明背景遮罩，点击可关闭
- **布局**：不遮挡底部信息栏，保留底部状态栏可见
- **样式**：玻璃态效果（backdrop-filter: blur(20px)），顶部圆角

### 2. 三栏布局

#### 左栏：分支列表
- **内容**：
  - 本地分支列表（带当前分支标记）
  - 远程分支列表（可折叠）
  - 每个分支显示：分支名、最后提交时间、提交者头像
- **交互**：
  - 单击分支：中栏显示分支详情，右栏显示改动文件
  - 右键分支：弹出操作菜单（切换、合并、删除等）
  - 悬停分支：高亮显示
- **样式**：
  - 当前分支：加粗 + 特殊图标
  - 分支图标：GitBranch（普通分支）、Dataflow02（worktree）

#### 中栏：分支详情
- **内容**：
  - 分支名称（大标题）
  - 最后提交信息：
    - 提交hash（可点击复制）
    - 提交消息
    - 作者信息（头像 + 名字）
    - 提交时间
  - 分支统计：
    - 领先/落后主分支的提交数
    - 文件改动统计（新增/修改/删除）
- **交互**：
  - 点击提交hash：复制到剪贴板
  - 点击作者：显示作者详情（可选）
- **样式**：
  - 信息分组展示
  - 使用图标增强可读性

#### 右栏：改动文件列表
- **内容**：
  - 文件列表，每个文件显示：
    - 改动状态图标（M=修改, A=新增, D=删除, R=重命名）
    - 文件路径
    - 改动行数统计（+行数/-行数）
- **交互**：
  - 单击文件：高亮显示
  - **双击文件**：弹出diff对比视图（左右分栏）
  - 右键文件：弹出操作菜单（查看历史、回滚等）
- **样式**：
  - 改动状态用不同颜色标识
  - 文件路径使用等宽字体

### 3. 右键菜单（分支操作）
当鼠标悬停在分支列表项上时，右键弹出菜单：

**菜单项**：
- **切换到此分支** (Switch to this branch)
  - 图标：GitSwitch
  - 快捷键提示：Enter
  - 仅对非当前分支显示

- **合并到当前分支** (Merge into current branch)
  - 图标：GitMerge
  - 快捷键提示：M
  - 显示目标分支名："合并 'feature-x' 到 'main'"

- **从当前分支合并** (Merge from current branch)
  - 图标：GitMerge
  - 仅当当前分支不是选中分支时显示

- **创建新分支** (Create new branch)
  - 图标：GitBranch + Plus
  - 快捷键提示：N
  - 弹出输入框输入新分支名

- **删除分支** (Delete branch)
  - 图标：Trash
  - 危险操作，红色文字
  - 需要二次确认
  - 不显示在当前分支上

- **在浏览器中查看** (View in browser)
  - 图标：ExternalLink
  - 仅对远程分支显示

### 4. Diff对比视图（双击文件触发）
当用户双击改动文件列表中的文件时，弹出diff对比视图：

**布局**：
```
┌──────────────────────────────────────────────────────────┐
│  文件: src/main.rs                            [×]        │
├──────────────────────────────────────────────────────────┤
│  ┌──────────────────────┬──────────────────────┐        │
│  │  旧版本      │  新版本      │        │
│  │  ────────────────────┼─────────────────────  │        │
│  │  1 | fn main() {     │  1 | fn main() {     │        │
│  │  2 |     let x = 1;  │  2 |     let x = 2;  │        │
│  │  3 | }               │  3 |     println!(); │        │
│  │                      │  4 | }               │        │
│  └──────────────────────┴──────────────────────┘        │
└──────────────────────────────────────────────────────────┘
```

**功能**：
- 左栏：旧版本（分支切换前/合并前）
- 右栏：新版本（当前状态）
- 高亮显示差异行：
  - 删除行：红色背景
  - 新增行：绿色背景
  - 修改行：黄色背景
- 行号对齐
- 支持滚动同步
- 关闭按钮：返回三栏视图

**交互**：
- 点击差异行：高亮对应的另一侧行
- 滚动一侧：另一侧同步滚动
- ESC键：关闭diff视图

## 数据契约

### 分支信息结构
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | String | 是 | 分支名称 |
| is_current | bool | 是 | 是否当前分支 |
| is_remote | bool | 是 | 是否远程分支 |
| last_commit | CommitInfo | 是 | 最后提交信息 |
| ahead | u32 | 否 | 领先主分支的提交数 |
| behind | u32 | 否 | 落后主分支的提交数 |

### 提交信息结构
| 字段 | 类型 | 说明 |
|------|------|------|
| hash | String | 提交hash |
| message | String | 提交消息 |
| author | String | 作者名称 |
| author_email | String | 作者邮箱 |
| timestamp | DateTime | 提交时间 |

### 改动文件结构
| 字段 | 类型 | 说明 |
|------|------|------|
| path | String | 文件路径 |
| status | FileStatus | 改动状态（M/A/D/R） |
| additions | u32 | 新增行数 |
| deletions | u32 | 删除行数 |

### Diff结构
| 字段 | 类型 | 说明 |
|------|------|------|
| old_content | String | 旧版本内容 |
| new_content | String | 新版本内容 |
| hunks | Vec<Hunk> | 差异块列表 |

## UI/UX设计规范

### 样式特征
- **背景**：玻璃态效果（backdrop-filter: blur(20px), bg-white/90）
- **边框**：顶部圆角（rounded-t-2xl）+ 微妙阴影（shadow-2xl）
- **动画**：
  - 滑入：transform: translateY(100%) → translateY(0), duration: 300ms, ease-out
  - 滑出：transform: translateY(0) → translateY(100%), duration: 200ms, ease-in
- **高度**：占屏幕 60-70%（max-h-[70vh]），底部留空间给状态栏
- **字体**：Inter字体，等宽字体用于代码和路径

### 颜色方案
- **主色**：#2563EB（蓝色，用于主要操作）
- **成功色**：#10B981（绿色，用于新增行）
- **危险色**：#EF4444（红色，用于删除行和危险操作）
- **警告色**：#F59E0B（黄色，用于修改行）
- **背景色**：#F8FAFC（浅灰背景）
- **文本色**：#1E293B（深灰文本）

### 交互规范
- **悬停**：背景色变化 + cursor-pointer
- **点击**：active:scale-95 轻微缩放
- **过渡**：transition-all duration-200
- **焦点**：focus:ring-2 focus:ring-blue-500
- **右键菜单**：在鼠标位置弹出，点击外部关闭

### 响应式设计
- **桌面**（>1024px）：三栏布局，左20% + 中40% + 右40%
- **平板**（768-1024px）：三栏布局，左25% + 中35% + 右40%
- **移动**（<768px）：单栏布局，堆叠显示

## 风险与注意
- ⚠️ **性能风险**：大型仓库可能有大量分支和文件，需要虚拟滚动
- ⚠️ **并发风险**：Git操作可能耗时，需要显示加载状态，防止重复操作
- ⚠️ **错误处理**：Git操作可能失败（冲突、权限等），需要友好的错误提示
- 💡 **快捷键**：支持键盘导航（上下键选择分支，Enter切换，ESC关闭）
- 💡 **缓存**：缓存分支列表和文件列表，减少Git命令调用
- 💡 **刷新**：提供手动刷新按钮，应对外部Git操作
